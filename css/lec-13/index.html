Display : Flex (Child Property) Flex-Grow

  • The flex-grow CSS property sets the flex grow factor, which specifies how much of the flex container's positive free space should be assigned to the flex item.
  • When the container has extra space, it is distributed among flex items according to their flex-grow values.
