Article 3: Introduction To CSS

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the design, layout, and visual appearance of a webpage written in HTML.
While HTML provides the content and structure, CSS adds the
styling—such as colors, fonts, spacing, and responsive design for different screen sizes.
